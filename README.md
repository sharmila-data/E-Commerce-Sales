# E-Commerce Sales Dashboard

## Project Overview
The E-Commerce Sales Dashboard is developed using Power BI to analyze sales revenue, profit, orders, profit margin, and customer sales distribution. It provides a clear overview of business performance through interactive charts, KPIs, and filters.

## Tools Used
- Power BI
- Microsoft Excel
- DAX

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Orders 
- Profit Margin

## Dashboard Features
- Sales Trend Analysis
- Sales by Place
- Share of Total
- Sales by City
- Detailed Records
- Interactive Filters

These filters help users explore sales data based on their selected requirements.

## Project Objectives
- Analyze total revenue and profit.
- Monitor sales trends over time.
- Identify cities with higher sales.
- Compare customer segment contributions.
- Analyze product categories and geographical performance.
- Support data-driven business decisions.

## Conclusion
This dashboard provides an interactive view of e-commerce sales performance. It helps users understand revenue trends, identify top-performing cities, compare customer segments, and monitor key business metrics for better decision-making.
